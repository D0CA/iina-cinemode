# Changelog

## 1.2.1

- Click anywhere except Resume / Search / Up next dismisses the pause overlay without resuming, so IINA settings stay reachable
- Two-finger swipe while paused hides the overlay without seeking, then shows the native IINA frame

## 1.2.0

- AniSkip for anime OP / ED / recap when TheIntroDB and chapters have nothing
- AniList score and studio on anime
- Pause overlay: air date, studio, episode runtime; year is not duplicated when a full date exists
- Preferences to hide cast, synopsis, progress bar, and Up next
- Up next opens the next episode page in Stremio (optional; does not start the next torrent)

## 1.1.0

- Search window: show → season → episode
- TheIntroDB skip timings
- Stremio next-episode shortcut
- Language prefs, audio / subtitle matching, window title
