CineMode affiche un overlay pause plein écran et un bouton Passer l’intro uniquement quand le timing est vraiment connu.

Prérequis

Une clé API TMDB gratuite : themoviedb.org/settings/api. Colle-la dans Préférences.

Identification

IINA ne reçoit souvent qu’une URL debrid. Si le titre n’est pas reconnu, pause → Rechercher un titre : clique la série, la saison, puis l’épisode. Si le fichier a déjà un SxxExx, CineMode saute à la bonne saison.

Skip

TheIntroDB, AniSkip (OP/ED anime), chapitres nommés Intro/Opening, ou marquage manuel. Pas d’estimation au pif. Raccourci : Shift+S.

À suivre

Optionnel. Ouvre la fiche du prochain épisode dans Stremio, pas le prochain torrent. Désactive dans Préférences si tu n’utilises pas Stremio.

Overlay pause

Clic n’importe où hors Reprendre / Recherche / À suivre : l’overlay disparaît, la vidéo reste en pause — tu peux changer sous-titres, chapitres, etc. Swipe deux doigts : l’overlay se cache sans avancer la vidéo, puis l’écran IINA s’affiche. Désactivable dans Préférences.
